A one-day front page summing up 20 November 2026 world news in one image: masthead THE WORLD TODAY, a lead story, and a ranked list of 32 stories from 6 continents, plus a wireframe globe and a BY THE NUMBERS strip.
Rendered procedurally in pure Python 3.13 standard library — no network, no fonts, no image libraries. Two runs produce byte-identical output.

## Run it

```sh
python3 main.py            # writes /output/entry.png
MAKEFUN_OUTPUT_DIR=out python3 main.py
```
